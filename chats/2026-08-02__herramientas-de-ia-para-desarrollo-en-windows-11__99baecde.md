### 1) Perspectiva científico-técnica

El criterio técnico no es “gratis sí/no”, sino **costo por token, contexto, latencia, capacidad agéntica y acceso a navegador**.

Codex CLI obtiene 83,4% en Terminal-Bench 2.1 según la comparativa de MorphLLM [[128]]. Gemini CLI ofrece 1 millón de tokens de contexto según Developers Digest [[122]]. La capa gratuita de Gemini CLI está limitada a 60 solicitudes por minuto y 1.000 solicitudes por día [[119]]. GitHub Copilot Free está limitado a 2.000 autocompletados y 50 chats mensuales [[93]]. OpenCode soporta más de 75 proveedores de LLM según NxCode [[5]]. OpenCode también aparece con 172K estrellas en la comparativa de MorphLLM [[128]].

En local, el trade-off es claro: los modelos locales permiten costo marginal cero, pero suelen perder calidad frente a modelos cloud para tareas complejas [[59]].

### 2) Perspectiva práctica Windows 11

En Windows 11, la fricción real está en **PATH, PowerShell, WSL, instaladores y permisos**.

OpenCode recomienda WSL en Windows [[2]]. También puede instalarse nativamente con Chocolatey [[77]]. La guía de instalación de OpenCode de 2026 menciona Chocolatey, Scoop, npm, Bun, pnpm y Mise [[78]]. Kilo Code requiere que PowerShell esté correctamente añadido al PATH en Windows [[70]]. Hay issues reportados donde Kilo falla cuando PowerShell no está bien configurado [[73]].

Cline se instala desde el Marketplace de VS Code [[102]]. Cline funciona con múltiples proveedores, incluidos OpenRouter, Anthropic, OpenAI, Google Gemini, AWS Bedrock, Azure y otros [[99]]. Cline separa Plan y Act para aprobar acciones [[64]]. Cline puede usar navegador para verificar UI [[69]]. Cline añadió integración con Chrome local en la versión 3.10 [[115]]. Hay un issue reportado donde `browser_action` falla en WSL [[113]]. En Windows, una guía comunitaria muestra conexión vía PowerShell [[111]].

Continue soporta Windows x64 y Windows ARM [[90]]. Continue puede configurarse con Ollama para ejecución local [[85]]. Continue fue adquirido por Cursor, aunque mantiene código abierto disponible [[87]].

GitHub Copilot Free funciona en VS Code [[93]]. También hay Copilot gratuito limitado en Visual Studio [[92]]. Visual Studio Community es gratuito para estudiantes, open-source e individuos [[53]].

OpenAI lanzó la app Codex para Windows el 4 de marzo de 2026 [[124]]. Codex CLI ofrece instaladores para Windows [[127]]. OpenAI envió Codex Computer Use para Windows el 29 de mayo de 2026 [[129]].

### 3) Perspectiva ético-histórica

El patrón histórico es claro: **los free tiers son embudos de adopción**.

Microsoft presenta Copilot como experiencia básica gratuita, con extras de pago [[156]]. En 2026, reportes de prensa indican que Microsoft reduce o replantea la integración de Copilot en Windows 11 [[140]]. Kilo muestra en 2026 una opción gratuita sin tarjeta [[72]]. Un sitio externo afirma que el free tier antiguo de Kilo terminó en marzo [[71]]. Continue sigue siendo open source tras su adquisición por Cursor [[87]]. Continue publica licencia Apache 2.0 [[90]].

Las herramientas open source no cobran por el cliente, pero trasladan el costo a tokens, infraestructura o hardware [[59]]. Los free tiers propietarios suelen limitar uso, modelos o capacidades agénticas [[59]]. La ejecución local con Ollama/Continue reduce la exposición de datos, pero exige hardware suficiente [[85]].

Microsoft también está construyendo una capa de IA local para Windows con Microsoft Foundry on Windows [[145]].

## Análisis por casos

### Caso 1: Quieres una web visual avanzada con animaciones y $0

**Recomendación principal:** Cline con proveedor gratuito/económico.

**Alternativa sin tarjeta:** Kilo Code.  
Kilo ofrece Kilo Auto Free sin tarjeta [[72]]. Kilo tiene límites gratuitos publicados [[76]]. Antes de depender de Kilo, verifica si el plan gratuito cambió [[71]].

**Advertencia:** para animaciones complejas, los modelos gratuitos pueden ser menos fiables que Claude/GPT/Gemini premium [[59]].

### Caso 2: Quieres privacidad total y cero costo por token

**Recomendación:** Continue + Ollama.  
Continue soporta Windows x64 y ARM [[90]]. Continue puede usar Ollama para modelos locales [[85]]. La ejecución local reduce dependencia de APIs externas [[85]].

**Advertencia:** los modelos locales suelen perder calidad en tareas complejas [[59]].

### Caso 3: Quieres terminal pura y máxima compatibilidad con APIs

**Recomendación:** OpenCode.  
OpenCode incluye modelos gratuitos o conexión a proveedores [[79]]. OpenCode puede instalarse con Chocolatey o Scoop [[77]]. OpenCode recomienda WSL en Windows [[2]]. OpenCode soporta más de 75 proveedores [[5]].

**Alternativas:** Gemini CLI ofrece capa gratuita con límites [[119]]. Gemini CLI ofrece contexto de 1M tokens [[122]]. Codex CLI lidera Terminal-Bench según MorphLLM [[128]]. Codex CLI tiene instaladores para Windows [[127]].

### Caso 4: Quieres algo oficial, simple y sin configurar agentes

**Recomendación:** GitHub Copilot Free.  
Copilot Free da 2.000 autocompletados y 50 chats al mes [[93]]. Copilot también tiene uso gratuito limitado en Visual Studio [[92]]. Visual Studio Community es gratis para individuos [[53]].

**Advertencia:** si haces desarrollo intensivo, el límite mensual se queda corto [[93]].

### Caso 5: Si “mejor” significa pagar poco o suscripción

**Recomendación:** Windsurf si quieres IDE pulido.  
Windsurf ofrece free tier con 25 créditos/mes [[28]]. Su plan de entrada cuesta alrededor de $20/mes [[27]].

**Alternativa:** Cline con API premium.  
Cline puede usar proveedores premium sin estar atado a una suscripción única [[99]].

## Ruta recomendada en Windows 11

### Ruta A: Front-end visual gratis con Cline

1. Instala VS Code.  
2. Instala Cline desde el Marketplace [[102]].  
3. Configura un proveedor: OpenRouter, Anthropic, OpenAI, Google Gemini, local u otro [[99]].

## Comparación densa de opciones gratuitas

### Cline
Cline es un agente open-source con Plan/Act, MCP y flujo terminal-first [[62]]. Addy Osmani lo describe como gratuito y de clase alta para VS Code [[66]]. Cline puede crear/editar archivos, ejecutar comandos y usar navegador con permiso [[69]]. Cline funciona con proveedores múltiples, incluyendo OpenRouter, Anthropic, OpenAI, Google Gemini, AWS Bedrock y Azure [[99]]. Cline permite integración con Chrome local [[115]]. Cline puede ser la mejor opción gratuita si ya tienes una clave API económica o gratuita [[66]].

### Kilo Code
Kilo Code se presenta como agente open source para IDE, CLI y nube [[7]]. Kilo afirma acceso a más de 500 modelos [[8]]. Kilo Auto Free se anuncia sin tarjeta [[72]]. Kilo publica límites para su capa gratuita [[76]]. Un sitio externo dice que el free tier antiguo terminó en marzo [[71]]. En Windows, Kilo requiere PowerShell correctamente configurado [[70]]. Hay issues de Kilo cuando PowerShell no está en PATH [[73]].

### OpenCode
OpenCode es un agente de código abierto para terminal, escritorio o extensión [[2]]. OpenCode ofrece modelos gratuitos incluidos o conexión a proveedores [[1]]. OpenCode puede instalarse en Windows con Chocolatey [[77]]. También puede instalarse con Scoop [[77]]. La guía 2026 menciona npm y otros gestores [[78]]. OpenCode soporta más de 75 proveedores [[5]]. OpenCode es recomendado si quieres una CLI agnóstica y sin suscripción fija [[79]].

### Continue
Continue es una extensión open-source de VS Code con agente, chat, edición y autocompletado [[90]]. Continue soporta Windows x64 y ARM [[90]]. Continue usa licencia Apache 2.0 [[90]]. Continue puede conectarse a Ollama para modelos locales [[85]]. Continue fue adquirido por Cursor [[87]]. Continue mantiene base de código open-source disponible [[87]].

### GitHub Copilot Free
GitHub Copilot Free ofrece 2.000 autocompletados/mes [[93]]. También ofrece 50 solicitudes de chat/mes [[93]]. Copilot Free funciona en VS Code [[93]]. Copilot también tiene versión gratuita limitada en Visual Studio [[92]]. Visual Studio Community es una opción gratuita de IDE para individuos [[53]].

### Gemini CLI
Gemini CLI es un agente open-source de Google para terminal [[120]]. Gemini CLI ofrece free tier de 60 solicitudes/min y 1.000 solicitudes/día [[119]]. Gemini CLI ofrece contexto de 1M tokens según análisis de terceros [[122]]. Gemini CLI es útil para proyectos grandes por contexto [[122]].

### Codex CLI / Codex App
Codex CLI es un agente de OpenAI que corre localmente en terminal [[127]]. Codex CLI ofrece instaladores para Windows [[127]]. La app Codex llegó a Windows el 4 de marzo de 2026 [[124]]. Codex Computer Use llegó a Windows el 29 de mayo de 2026 [[129]]. Codex CLI aparece con 83,4% en Terminal-Bench 2.1 según MorphLLM [[128]].

### Windsurf
Windsurf tiene free tier con 25 créditos/mes [[28]]. Windsurf es considerado un editor AI pulido, con precio de entrada alrededor de $20/mes [[27]]. Si tu prioridad es experiencia visual sin configurar proveedores, Windsurf puede ser mejor que una opción gratuita limitada [[27]].

### Aider
Aider es un agente de programación en terminal [[14]]. Aider es recomendado para desarrolladores senior que trabajan con Git [[19]]. Si tu flujo es Git-heavy, Aider puede ser mejor que Cline para auditoría de cambios [[19]].

### Goose
Goose es un agente open-source de propósito general que corre en tu máquina [[131]]. Goose tiene CLI y aplicación de escritorio [[136]]. Goose aparece en comparativas de herramientas CLI gratuitas [[125]].

## Glosario operativo

**BYOK**: Bring Your Own Key; el usuario aporta su propia clave API. Cline funciona con este enfoque [[64]].

**Agente**: sistema que puede leer, editar, ejecutar y verificar tareas. Cline se describe como agente de codificación [[62]].

**CLI coding**: programación asistida desde terminal. OpenCode es un agente de terminal [[1]].

**Free tier**: capa gratuita con límites. Copilot Free tiene límites mensuales [[93]].

**Token/contexto**: cantidad de información que el modelo puede procesar. Gemini CLI ofrece contexto amplio [[122]].

**Browser action**: capacidad de controlar un navegador para verificar UI. Cline incluye esta capacidad [[69]].

**Plan/Act**: modo de razonamiento y modo de ejecución. Cline usa esta separación [[64]].

**MCP**: Model Context Protocol; estándar para conectar herramientas externas. Cline menciona integración MCP [[62]].

**Ollama**: runtime local para modelos abiertos. Continue puede usar Ollama [[85]].

**WSL**: Windows Subsystem for Linux. OpenCode lo recomienda en Windows [[2]].

**Terminal-Bench**: benchmark de agentes de terminal. Codex CLI aparece bien puntuado allí [[128]].

**Computer Use**: agente que opera interfaz/escritorio. Codex Computer Use llegó a Windows en 2026 [[129]].

## Reflexión prospectiva

El patrón de 2026 es claro: los agentes dejan de ser chatbots y se convierten en procesos que editan, ejecutan, navegan y verifican. OpenAI llevó Codex Computer Use a Windows el 29 de mayo de 2026 [[129]]. Microsoft impulsa IA local con Foundry on Windows [[145]]. Los free tiers seguirán siendo embudos con límites [[59]]. La competencia se desplazará hacia hardware local, privacidad, contexto largo y costo por tarea.

Pregunta guía: **¿Prefieres $0 absoluto con hardware local, $0 con límites en nube, o pagar poco por una calidad visual superior?**
